# 時代華語 2 完課測驗（團班版）

第 1～16 課的完課測驗。學生打開網頁、寫班級座號姓名就能考試，交卷以後成績會自動寫進老師的 Google 試算表。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 首頁，列出 16 課 |
| `L01.html` ～ `L16.html` | 每一課的測驗 |
| `config.js` | **老師唯一要改的檔案**：放成績表的網址 |
| `apps-script.gs` | 貼到 Google 試算表的程式（接收成績用） |

## 一次性設定（大約 10 分鐘）

### 1. 建立成績表
1. 到 Google 雲端硬碟，新增一個 Google 試算表，取名例如「時代華語2 成績」。
2. 上方選單：**擴充功能 → Apps Script**。
3. 把編輯器裡原本的程式全部刪掉，貼上 `apps-script.gs` 的全部內容，按「儲存」。

### 2. 發布成網頁應用程式
1. 右上角 **部署 → 新增部署作業**。
2. 「選取類型」按齒輪 → **網頁應用程式**。
3. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按「部署」，第一次會要你授權，選你的 Google 帳號 → 「進階」→「前往（不安全）」→「允許」。
5. 複製出現的 **網頁應用程式網址**（`https://script.google.com/macros/s/……/exec`）。

### 3. 把網址貼進 `config.js`
```js
window.QUIZ_CONFIG = {
  SCRIPT_URL: "https://script.google.com/macros/s/……/exec",
  DEFAULT_CLASS: ""
};
```

### 4. 放到 GitHub Pages
1. 在 GitHub 建一個新的 repository（例如 `mc2-quiz`），把這個資料夾裡的檔案全部上傳。
2. Repository 的 **Settings → Pages**，Source 選 `main` branch、`/ (root)`，按 Save。
3. 一、兩分鐘後網址會出現，例如 `https://你的帳號.github.io/mc2-quiz/`。
4. 給學生的連結：
   - 首頁：`https://你的帳號.github.io/mc2-quiz/`
   - 單課：`https://你的帳號.github.io/mc2-quiz/L03.html`

> 建議先自己用「測試」的名字考一次，確認試算表有出現資料，再把連結給學生。

## 成績表裡會看到什麼

- **成績冊**：一位學生一列，L01～L16 每課一欄（百分制），最後一欄是平均。
  - 預設記「第一次」交卷的分數。想改成最高分或最後一次，把 `apps-script.gs` 第一行的 `SCORE_POLICY` 改成 `"best"` 或 `"latest"`，再重新部署。
  - 同一課交卷超過一次，儲存格會有註解寫「交卷 N 次，最新一次 X 分」。
- **作答紀錄**：每次交卷一列，有交卷時間、第幾次、得分、各大題分數、作答分鐘、所有錯題（學生選了什麼、正確答案是什麼）。

學生是用「班級＋座號＋姓名」辨認的，請提醒學生每次都寫一樣的。

## 學生端的規則

- 每個大題只能做一次，做的時候不會顯示對錯。
- 全部做完按「交卷」，成績自動送出，然後才能看答案和說明。
- 想重考可以按「再考一次」，新的成績也會送出（成績冊預設仍記第一次）。
- 如果網路有問題沒送出去，畫面會出現「複製」按鈕，學生可以把成績貼給老師。

## 之後改了 Apps Script 怎麼辦？

在 Apps Script 按 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，網址不會變，不用改 `config.js`。
